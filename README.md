# Hextree Android Security Course's Notes

This repo is the notes and challenge solutions I came up with when going through [Hextree.io](https://www.hextree.io/) Android Security crash course.

It is supposed to be a reference for doing deeper android research as it contains a lot of obscure details (or just details that are hard to come by in the official android docs).

> P.S: The course is very good introduction to android security in my opinion and is worth checking out!
